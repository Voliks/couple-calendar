# Календарь на двоих — Telegram Mini App

Бот (aiogram 3), HTTP API (aiohttp) и фронтенд (чистый HTML/JS/CSS) работают в одном процессе.
База — SQLite локально или Turso в продакшене.

## Структура

```
main.py            точка входа: бот, HTTP API, напоминания, раздача фронтенда
common.py          настройки, константы, bot, отправка уведомлений
voice.py           голосовые заметки (Groq Whisper + LLM)
db.py              схема, миграции и запросы
sex_ideas.json     встроенные идеи для категории «Секс»
webapp/index.html  Mini App
webapp/css/        стили
webapp/js/         api.js, calendar.js, list.js, ideas.js, form.js, main.js
.env.example       пример настроек
requirements.txt
```

## Запуск локально

1. Создайте бота у @BotFather и получите токен.
2. Установите зависимости:
   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните как минимум `BOT_TOKEN` и `WEBAPP_URL`.
4. Telegram открывает Mini App только по HTTPS. Для разработки пробросьте порт:
   ```bash
   cloudflared tunnel --url http://localhost:8080   # или: ngrok http 8080
   ```
   Полученный https-адрес пропишите в `WEBAPP_URL`.
5. Запустите `python main.py`, откройте бота, нажмите /start и «📅 Открыть Календарь».

В `webapp/index.html` в `<meta name="api-base">` указан адрес API. Если фронтенд раздаётся тем же сервером,
оставьте значение пустым; для разработки впишите свой туннель.

## Деплой на Render

- Задайте переменные окружения из `.env.example`, особенно `BOT_TOKEN`, `WEBAPP_URL`, `TURSO_URL`, `TURSO_TOKEN`.
  Без Turso база лежит на временном диске и **пропадает при каждом деплое**.
- На бесплатном тарифе сервис засыпает без входящих запросов. Вместе с ним «спят» бот и напоминания.
  Настройте внешний пинг `https://<ваш-домен>/health` каждые 5 минут (например, UptimeRobot) или возьмите платный тариф.
- Запускайте только один экземпляр: два процесса с одним токеном конфликтуют в long polling.

## Как связать пару

Если партнёр не привязан, Mini App показывает экран с кнопкой «Отправить ссылку партнёру».
Ссылка имеет вид `https://t.me/<bot>?start=ref_<КОД>`; её же выдаёт команда `/invite`.
Ссылка действует 7 дней. После перехода по ней оба получают доступ к календарю.

## Напоминания

Для дел и личных событий с временем можно выбрать «напомнить за …». Напоминание уходит, как только время подошло,
и пока событие не началось, поэтому после короткого простоя сервера оно не теряется.
Для остальных событий в день события приходит напоминание в `REMINDER_HOUR` по времени пользователя.
При изменении даты, времени или срока напоминания оно сбрасывается и сработает заново.

## Голосовые заметки

Отправьте боту голосовое сообщение (до 90 секунд), например «завтра купить молоко и хлеб» или «в пятницу в 18:00 позвонить маме».
Нужен `GROQ_API_KEY`. **Аудио и распознанный текст передаются в Groq** — сообщите об этом пользователям.
Личные заметки, созданные голосом, видны только автору.

## Безопасность

Фронтенд отправляет на сервер `Telegram.WebApp.initData`, а сервер проверяет его HMAC-подпись токеном бота
(`safe_parse_webapp_init_data`) и не принимает «голый» `initDataUnsafe.user.id`. Сессия действует 24 часа,
после чего приложение просит открыть его заново. Сервер проверяет, что на событие отвечает только адресат
и только пока статус `pending`; категорию существующего события менять нельзя.
